How this works

1. Serve this folder with a local HTTP server (for example python -m http.server 8000), then open http://localhost:8000/. No internet connection required. Put images in the images folder beside this HTML file, named by item ID (for example TOP-001.jpg). JPG, JPEG, PNG, WEBP and AVIF are supported.

2. Browse outfit ideas, filter by weather and occasion, or open an outfit in Mix & match to modify it.

3. New outfits are stored in your browser's local storage, which may disappear if browser data is cleared or you switch browsers. Export your catalog JSON after making changes.

4. Use Import catalog to restore saved outfits or load an updated catalog from a future chat. To replace a photo, save your preferred product image to the images folder under the item ID. Reload the HTML page. For new clothing items, update the inventory JSON and refresh the page.

5. The wardrobe includes four pairs of shoes, including formal black dress shoes. Temperature ranges are approximate. This is not a virtual fitting tool and reference images are not a virtual try-on.
